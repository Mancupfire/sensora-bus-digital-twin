Compare AI predictions with the CFD reference

Three neural networks were trained on part of this one CFD simulation and then asked to fill in the regions they never saw. Below: the same slice and the same colour scale for the CFD reference and each network. All values are precomputed.

CFD reference images

Images supplied with the simulation case. They were not made by this demo. The positions of the section planes were not recorded, so each plane below is estimated by matching the image colours to the exported data. This is a visual consistency check, not a numerical validation.

This public build does not include the supplied CAD view and STAR-CCM+ renders, because permission to publish them has not been confirmed. They are kept in the local / offline version.

Results & metrics

One steady RANS scenario · VinBus cabin · CFD samples. The task is spatial reconstruction of this one simulation: whole blocks of the cabin were hidden from training, and the networks had to fill them in.

Vanilla DeepONet

An MLP branch over the flattened, canonically ordered boundary samples.

PN-DeepONet

A PointNet branch over the same boundary samples, treated as a point set.

PI-PN-DeepONet

PN architecture, warm-started from the selected PN, plus compressible continuity and boundary-condition terms. Not full-RANS physics: momentum and energy are off because k and ε were not exported.

Train / validation / test split

The cabin is cut into about 0.5 m blocks. Whole blocks are held out: 70 % train, 15 % validation, 15 % test, with a 5 cm buffer. Validation chose the checkpoints. Test was scored once, after every checkpoint was frozen.

This is spatial reconstruction of one scenario, not a surrogate that predicts new HVAC settings. With one scenario the boundary input never changes, so the response to different conditions is untested.

Pressure

The networks also predict the working pressure (Pa). It is not shown in the main view because differences of a few pascals are hard to read without context; open the Error explorer to see it.
